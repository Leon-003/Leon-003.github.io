# Abul Khayer Leon — Final Portfolio

Clean, responsive, deployment-ready personal portfolio built with HTML, CSS and vanilla JavaScript.

## Files
- `index.html`
- `styles.css`
- `script.js`
- `passport.png`
- `Abul_Khayer_Leon_CV.pdf`

## Included interactions
- Responsive mobile navigation
- Dark/light theme toggle
- Scroll progress bar
- Scroll-reveal animations
- Project category filters
- Active navigation highlighting
- Real GitHub, ResearchGate, LinkedIn, Codeforces, VJudge and email links
- CV download

## Deployment
Upload all files to the root of the `Leon-003.github.io` repository and keep GitHub Pages configured to deploy from `main` / root. No build command is required.

Section and project numbering has been intentionally removed for a cleaner professional portfolio style.
